# Titanic Classification – Multiple Models & Feature Selection 🧠

This project was developed as part of a Machine Learning course.  
It continues the work from the [Titanic Logistic Regression Project](https://github.com/Itamar-Hadad/titanic-logistic-regression), using more advanced classification models and feature selection techniques.

## 📌 Objective
Use the Titanic dataset to predict passenger survival using a variety of classifiers and validation methods.

## 🔍 Key Components

### 1. 🧪 Models Used
- **K-Nearest Neighbors (KNN)**
- **Support Vector Machine (SVM)**
- **Naive Bayes Classifier (NBC)**
- **Linear Discriminant Analysis (LDA)**

### 2. 🔁 Validation Technique
- Bootstrap sampling used for validation
- Performance measured using accuracy and other classification metrics

### 3. 🛠️ Feature Selection
- Forward Selection
- Backward Elimination
- Hybrid Methods
- Tested multiple subsets of features to improve results

### 4. 📊 Evaluation
- Confusion Matrix
- KPIs: Accuracy, Precision, Recall, F1-Score
- Graphs comparing training vs validation loss/accuracy
- Analysis of model behavior and performance tradeoffs

## 🛠️ Technologies Used
- Python  
- scikit-learn  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Jupyter Notebook (Kaggle)

## 📁 Files
- `Titanic.ipynb` – Notebook with full analysis
- `submission.csv` – File submitted to Kaggle

## 📚 What I Learned
- How different classifiers perform on the same data
- When and how to use feature selection to improve generalization
- Validation with bootstrapping vs fixed split
- Proper use of confusion matrix and KPIs in real evaluation
